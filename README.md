# Плагин «Ступенчатая втулка» для КОМПАС-3D

Лабораторные работы по дисциплине «Основы разработки САПР» (ТУСУР, кафедра КСУП).

Программа (плагин/приложение) для САПР КОМПАС-3D, которая по заданным
пользователем параметрам строит параметрическую 3D-модель детали
«Ступенчатая втулка» с проверкой корректности введённых значений.

## Параметры модели

| Параметр | Диапазон, мм | Значение по умолчанию, мм | Зависимость |
|---|---:|---:|---|
| D1 — наружный диаметр большей ступени | 30–120 | 40 | D1 > D2 |
| D2 — наружный диаметр меньшей ступени | 20–110 | 30 | D2 ≥ d + 2·S, D1 > D2 |
| d — диаметр сквозного отверстия | 6–90 | 26 | d ≤ D2 − 2·S, d ≤ D1 − 2·S |
| L1 — длина большей ступени | 2–20 | 10 | — |
| L2 — длина меньшей ступени | 5–200 | 50 | — |

Константа: `S = 2 мм` — минимальная толщина стенки.

Зависимые ограничения:
- `d + 2*S <= D2` (минимальная толщина стенки меньшей ступени);
- `d + 2*S <= D1` (минимальная толщина стенки большей ступени);
- `D1 > D2` (сохранение большей и меньшей ступеней).

При изменении `D2` пересчитывается допустимый диапазон `d`: `d_max = D2 - 2*S`.  
При изменении `d` пересчитывается допустимый диапазон `D2`: `D2_min = d + 2*S`.

## Функциональность

- ввод 5 параметров детали через поля ввода;
- автоматическая валидация диапазонов и зависимых параметров `D2` и `d`;
- построение 3D-модели «Ступенчатая втулка» в КОМПАС-3D по параметрам;
- повторное построение при изменении параметров;
- вывод сообщений об ошибках (валидация/ошибки API).
